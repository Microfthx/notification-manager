# Logs Directory

This directory contains log files generated by the notification manager. The logs are essential for monitoring the performance and behavior of the notification bots.

## Log Files

- **error.log**: Contains error messages and stack traces for debugging purposes.
- **info.log**: Contains informational messages about the normal operation of the application.
- **debug.log**: Contains detailed debug information, useful for development and troubleshooting.

## Usage

Logs can be viewed to understand the state of the notification bots, troubleshoot issues, and ensure that the bots are functioning as expected. It is recommended to regularly check the logs for any anomalies or errors.

## Log Rotation

To manage disk space, it is advisable to implement log rotation. This can be done using tools like `logrotate` or by configuring the logging library used in the application to handle log rotation automatically.
